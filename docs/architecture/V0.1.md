# Ramathix Engineering AI — V0.1 Foundation

## Goal

Establish a safe local execution foundation before autonomous code changes are enabled.

## Runtime flow

```text
REA CLI
  -> GitHub Issue adapter
  -> Tech Lead Agent
  -> Model Router
  -> Ollama
  -> Governance Gate
  -> Docker Sandbox
  -> Audit Log
```

## Governance invariants

1. LLMs never receive unrestricted shell access.
2. Every command is evaluated by the central allowlist before execution.
3. Unknown commands require explicit approval.
4. Destructive commands are denied.
5. Any action with possible monetary cost requires human approval.
6. Production credentials are separate, scoped and read-only in the initial production phase.
7. Secrets must never be written to the audit log.

## V0.1 scope

- CLI entrypoint (`rea`)
- Ollama model router
- GitHub Issue retrieval
- Tech Lead structured issue analysis
- command policy engine
- Docker sandbox executor
- JSONL audit log with redaction
- draft GitHub PR adapter for later workflow phases
- CI for lint and tests

## Explicit non-goals

V0.1 does not yet allow a model to autonomously edit a repository, push a branch or merge code. Those capabilities are added only after the knowledge engine and workflow state machine have their own evaluations and approval gates.
