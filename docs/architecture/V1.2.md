# REA V1.2 — Ciclo autônomo de skills

A V1.2 acrescenta um subsistema nativo para o REA descobrir capacidades ausentes, gerar,
validar, registrar, ativar, observar e reverter skills.

## Ciclo completo

1. Eventos `skill.missing`, `intent.unsupported` e `tool.unavailable` alimentam o
   `SkillGapDetector`.
2. Uma proposta só nasce após evidências recorrentes.
3. `CommandSkillGenerator` delega a criação ao agente ou modelo local configurado.
4. O pacote deve conter `skill.json`, `SKILL.md` e um entrypoint interno.
5. `SkillValidator` valida esquema, limites, caminhos, padrões perigosos e integridade.
6. Os comandos de aceitação executam em Docker sem rede, somente leitura, sem capabilities,
   com limites de CPU, memória, PIDs e tempo.
7. `SkillRegistry` registra cada versão atomicamente e impede versões duplicadas.
8. `SkillLifecycle` ativa somente pacotes validados e dependências disponíveis.
9. Permissões protegidas exigem uma aprovação explícita com o mesmo nome da permissão.
10. Cada uso registra sucesso, latência, custo e falhas de segurança.
11. O reconciliador compara as métricas com o SLO do manifesto.
12. Violação de integridade coloca a skill em quarentena; regressão restaura a versão anterior.

## Contrato do pacote

`skill.json`:

```json
{
  "id": "skill-exemplo",
  "name": "Skill Exemplo",
  "version": "1.0.0",
  "description": "Descrição mensurável da capacidade.",
  "entrypoint": "main.py",
  "permissions": [],
  "dependencies": [],
  "validation_commands": [["python", "-m", "compileall", "."]],
  "minimum_success_rate": 0.8,
  "minimum_observations": 5,
  "max_latency_seconds": 120
}
```

O `SKILL.md` contém as instruções completas para os agentes. O registro usa SHA-256 de todos
os nomes e conteúdos, de modo que qualquer alteração posterior invalida a ativação.

## Operação

```bash
rea-skills discover --audit .rea/audit.jsonl

rea-skills cycle \
  --generator-command rea-skill-generator \
  --minimum-occurrences 2 \
  --max-skills 1

rea-skills record skill-exemplo --success --latency 2.4
rea-skills reconcile
rea-skills status
```

O comando gerador recebe, ao final dos argumentos, os caminhos do arquivo de proposta e do
diretório de saída. Também recebe `REA_SKILL_PROPOSAL` e `REA_SKILL_OUTPUT`.

## Limites de autoridade

Skills com acesso a credenciais, rede externa, produção, exclusão de dados, merge, governança ou
gestão de outras skills não são ativadas sem aprovação explícita. A própria skill não pode
conceder essa aprovação. O ciclo falha de forma segura quando Docker não está disponível ou a
validação isolada não termina.
